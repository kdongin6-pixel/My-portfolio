# 포트폴리오 읽기전용 UI 검증 및 데이터 계약

## 범위
- 기존 종목·시장·상세 화면을 확장. 새 분석 탭·주문·환전·증권사 계좌조회 API를 추가하지 않는다.
- 수량·평단·현금·원장 거래는 시세 어댑터에서 수정하지 않는다. 기존 클라우드 원장 병합은 유지한다.
- 분석용 복사/CSV는 현재 계좌 필터를 적용하며 거래내역·인증정보·계좌번호·내부 sourceId를 직렬화하지 않는다. 내보낸 잔고 자체는 개인정보이므로 사용자가 보관·전달 범위를 결정한다.

## 시세 계약
`src/portfolio-read.js`는 row의 `_quoteMetadata` 또는 최상위 필드를 읽는다.
- `quoteSource`, `quoteObservedAt`, `quoteRequestedAt` / `quoteQueriedAt` / `queriedAt`, `quoteMode`, `quoteSession`.
- 메리츠 `meritz-openapi`, `meritz-openapi-cache`, `sheet-fallback`을 지원. 미국 `yahooData[ticker]` 경로에서도 같은 메타데이터를 유지한다.
- `quoteQuality` 배열의 `account,ticker,cached`를 수신한다. `rateQuality`와 `quoteProvider`도 상태에 보존한다.
- 거래소 관측시각 null을 API 조회시각으로 대체하지 않는다. 유형·장구간 미제공은 미확인이다. 장 운영시간만으로 LIVE를 표시하지 않는다.
- 잘못된 가격은 이전 유효값이 있으면 이전 시세로 표시하며, 없으면 미확인이다. 합계의 평가 가능/확인 범위를 별도 표시한다. 불완전 평가를 전체 손익·비중 분석으로 출력하지 않으며 불완전한 새 스냅샷도 만들지 않는다.
- 환율 기준시각 미제공은 추정 환율로 명시하고 환차손익을 분해하지 않는다.

## 가격 이력 및 이벤트
- 종목별 선택적 `priceHistory: [{date,price}]` + `priceHistorySource`를 지원한다. 날짜/시각이 파싱 가능하고 가격이 양수인 실제 관측치 2개 이상 및 출처가 있어야 차트를 표시한다.
- `S.priceHistory[ticker]`와 `S.priceHistorySource`도 읽기전용 입력으로 지원한다. 원장 거래는 계좌와 티커(없으면 명칭)를 함께 맞춰 표시한다.
- 날짜 없는 legacy 시장 history 숫자 배열은 관측순서/기간 미확인으로만 표시한다. 날짜를 만들어 원장 마커와 정렬하지 않는다. 데이터 없는 스파크라인 생성 폴백을 제거했다.
- 사용자 일지 이벤트는 기존 `journal.stockName`으로 연결한다. 선택적 `S.events`의 `ticker,date,title,source,asOf`는 출처/공식 여부 확인 필요를 명시하여 표시한다. 서버의 메리츠 시세 전용 일봉 응답이 priceHistory와 출처로 전달된다. 날짜만 제공된 일봉에는 거래시각을 만들어 넣지 않는다. 공식 이벤트 API는 추가하지 않으며, 미제공 이벤트/가격이력은 빈 상태다.
- 종목 가격 차트와 기존 자산 스냅샷 추이는 서로 대체하지 않는다. 수정주가·배당·분할·장외 포함 여부는 미확인이다.

## 로컬 smoke (배포 아님)
1. 격리 worktree에서 `python -m http.server 8769 --bind 127.0.0.1` 실행 후 브라우저로 localhost:8769 접속.
2. 390×844에서 새 프로필은 설정/미연결 상태, 총자산 `—`를 확인. 설정 닫기 후 가로 넘침이 없는지 확인.
3. 실제 인증정보는 코드·테스트 fixture에 복사하지 말 것. 운영 계좌가 아닌 synthetic fixture로 정상/부분/빈 원장/로딩/실패 전환을 확인.
4. 종목 카드의 수량·평단·조회가격·통화·원가대비 손익·비중, 거래시각 미제공/조회시각 분리를 확인.
5. 종목명 버튼 → 바텀시트. Tab/Shift+Tab 포커스 순환, Escape/닫기/배경 클릭 종료와 원래 종목명 포커스 복귀를 확인. 원장 기록은 실제 증권사 주문이 아님.
6. 분석용 복사 및 CSV 다운로드. 클립보드 차단 시 직접 복사 textarea가 열리는지 확인. CSV에서 coverage행·현금행·빈 미확인 가격·시세 출처/시각 확인. 합성 악성 명칭 `=...`의 수식 실행 방지 접두문자를 확인.
7. 기존 시장 탭: 보유 태그, 금리/FX/지수 교육 문구, 출처/기준시각/다음 발표 미확인을 확인. 이력 없는 종목은 차트를 만들지 않아야 한다.
8. 모듈 변경 후 브라우저 전체 새로고침. 런타임 ES module 캐시는 같은 페이지의 이미 import한 모듈을 교체하지 않는다. 서비스워커 네트워크 우선 및 `pf-cache-v2-20261109` 캐시 버전 사용.
